## What changed

- Added a private React job tracker in `jobs-app/` with sign-in, job editing, search, filters, and live cross-device updates.
- Added versioned Supabase migrations for stronger row security, normalized job/CV fields, useful indexes, automatic timestamps/versioning, and Realtime publication.
- Preserved and backfilled the existing job records.

## Why

Supabase is now the single online source of truth, so a user signs in from any browser instead of connecting a database on each device.

## Impact

The existing public portfolio remains unchanged. The new tracker can be deployed separately to `jobs.ezherebetskii.com` after this PR is merged and its two public Supabase environment values are configured in Cloudflare Pages.
